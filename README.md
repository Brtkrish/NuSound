# NuSound

A modern music streaming web application built with Next.js and TypeScript, designed to provide a clean and interactive interface for discovering and listening to music.

## Overview

NuSound is a web-based music application focused on providing a smooth and responsive audio experience through a modern frontend.

The project was built using Next.js and TypeScript with a component-based architecture and a responsive user interface.

## Features

- Modern music streaming interface
- Responsive user interface
- Music discovery and browsing
- Audio playback experience
- Reusable UI components
- Responsive design for different screen sizes
- Deployed web application

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- Vercel

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Brtkrish/NuSound.git
cd NuSound
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
